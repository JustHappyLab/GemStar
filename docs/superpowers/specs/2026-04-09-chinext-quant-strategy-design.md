# 创业板量化交易策略设计文档

日期: 2026-04-09

## 1. 概述

构建一个针对 A 股创业板(300xxx/301xxx)的日频量化交易策略，结合:
- **时序模型(LSTM/GRU)** 做指数级择时 — 控制仓位
- **StockRank 多因子打分模型** 做选股 — 选择标的

本金 10 万元，回测近 5 年数据(2021-04-09 ~ 2026-04-09)。

## 2. 策略架构: 串行两层

```
Layer 1: 择时 (Timer)
  创业板指(399006.SZ) → LSTM/GRU → 仓位信号(0% / 50% / 100%)

Layer 2: 选股 (StockRank)
  创业板全股票池 → 多因子打分 → Top-5 排序

组合: 仓位信号 × Top-5 等权分配 → 每日目标持仓
```

择时和选股完全解耦，可独立评估和调优。

## 3. 数据层

### 3.1 数据源: Tushare

| 接口 | 用途 | 频率 |
|------|------|------|
| `stock_basic` | 创业板股票池(筛选 300xxx/301xxx) | 一次性 |
| `trade_cal` | 交易日历 | 一次性 |
| `pro_bar(adj='qfq')` | 个股日线行情(前复权) | 按年分段拉取 |
| `daily_basic` | PE/PB/换手率/总市值/流通市值 | 按年分段拉取 |
| `fina_indicator` | ROE/营收增速/净利润增速/毛利率 | 按年分段拉取 |
| `index_daily(ts_code='399006.SZ')` | 创业板指日线行情 | 一次性 |

### 3.2 数据缓存策略

- 所有原始数据缓存到 `data/raw/` 目录，parquet 格式
- 命名规范: `{接口名}_{标的或范围}_{start}_{end}.parquet`
- 增量更新: 检查已有数据的最大日期，只拉取增量部分
- 处理后的特征数据缓存到 `data/features/`

### 3.3 数据清洗规则

- 剔除 ST/*ST 股票
- 剔除上市不满 60 个交易日的次新股
- 剔除停牌日无行情的记录
- 财务数据按报告期对齐，使用最近一期可获取数据(避免前视偏差)
- 缺失值: 数值因子用截面中位数填充，仍缺失则剔除该股该日

## 4. 择时模块 (Timer)

### 4.1 输入特征

基于创业板指(399006.SZ)日线数据，构建 60 日滑窗特征:

| 特征类别 | 具体特征 | 说明 |
|----------|----------|------|
| 价格特征 | 5/10/20/60日收益率 | `close/close.shift(n) - 1` |
| 价格特征 | 5/10/20/60日均线偏离度 | `(close - MA_n) / MA_n` |
| 波动特征 | 5/10/20日波动率 | 对数收益率的滚动标准差 |
| 成交特征 | 5/10/20日成交量变化率 | `vol_ma5 / vol_ma20 - 1` |
| 动量特征 | RSI(14) | 相对强弱指标 |
| 动量特征 | MACD(12,26,9) | DIFF, DEA, MACD柱 |
| 趋势特征 | ADX(14) | 趋势强度 |

总特征维度: ~20 个

### 4.2 标签定义

未来 N 日(N=5)创业板指收益率:
- 收益率 > +1% → 标签 2 (看多, 目标仓位 100%)
- 收益率 在 [-1%, +1%] → 标签 1 (中性, 目标仓位 50%)
- 收益率 < -1% → 标签 0 (看空, 目标仓位 0%)

### 4.3 模型结构

```
Input(20 features × 60 timesteps)
  → LSTM(64 units) + Dropout(0.3)
  → LSTM(32 units) + Dropout(0.3)
  → Dense(16, relu)
  → Dense(3, softmax)  # 三分类: 看空/中性/看多
```

备选: GRU 替代 LSTM，参数更少，训练更快，作为对比实验。

### 4.4 训练策略

- **数据划分**: 滚动窗口(expanding window)
  - 初始训练集: 前 2 年
  - 验证集: 紧接着的 6 个月
  - 测试集: 紧接着的 6 个月
  - 每 6 个月滚动重训一次
- **损失函数**: Categorical Crossentropy
- **优化器**: Adam, lr=1e-3, 带余弦退火
- **早停**: patience=10, 监控验证集 loss
- **正则化**: Dropout(0.3) + L2(1e-4)

### 4.5 仓位信号输出

```python
probas = model.predict(X)  # shape: (3,)
position_signal = probas[2] * 1.0 + probas[1] * 0.5 + probas[0] * 0.0
# position_signal 是 [0, 1] 之间的连续值
# 离散化: < 0.3 → 0%, 0.3~0.7 → 50%, > 0.7 → 100%
```

### 4.6 择时模块的独立评估指标

- 方向准确率(多/空/中性三分类准确率)
- 择时夏普比率(仅按仓位信号交易创业板指 ETF 的收益)
- 最大空仓回避跌幅(大跌期间是否成功空仓)

## 5. 选股模块 (StockRank)

### 5.1 因子体系

| 类别 | 因子 | 数据来源 | 方向 | 权重 |
|------|------|----------|------|------|
| 盈利质量 | ROE(TTM) | `fina_indicator.roe` | 正 | 15% |
| 成长性 | 营收同比增速 | `fina_indicator.revenue_yoy` | 正 | 15% |
| 成长性 | 净利润同比增速 | `fina_indicator.netprofit_yoy` | 正 | 10% |
| 估值 | PE(TTM) 倒数 | `daily_basic.pe_ttm` | 正(倒数) | 10% |
| 估值 | PB 倒数 | `daily_basic.pb` | 正(倒数) | 10% |
| 动量 | 20日收益率 | `pro_bar` 计算 | 正 | 15% |
| 流动性 | 20日平均换手率 | `daily_basic.turnover_rate` | 正 | 10% |
| 相对强弱 | 相对创业板指超额收益(20日) | 计算 | 正 | 15% |

### 5.2 因子处理流程

```
原始因子值
  → 极值处理: MAD 法, 3 倍绝对中位差截断
  → 标准化: 截面 Z-Score (每日截面)
  → 缺失处理: 截面中位数填充
  → 加权合成: 总分 = Σ(权重_i × 标准化因子_i)
  → 排序: 按总分降序
  → 输出: Top-5 候选列表
```

### 5.3 因子更新频率

- **技术面因子**(动量/换手率/相对强弱): 每日更新
- **估值因子**(PE/PB): 每日更新(daily_basic 提供)
- **基本面因子**(ROE/营收增速/净利润增速): 按季报更新
  - 使用最近一期已公开的财报数据(考虑披露日期，避免前视偏差)
  - 季报公布周期: Q1 在 4/30 前, 半年报 8/31 前, Q3 在 10/31 前, 年报 4/30 前

### 5.4 选股模块的独立评估指标

- 因子 IC/IR(每个因子对未来 5 日收益的信息系数)
- Top-5 组合相对创业板指的超额收益
- 因子多空组合收益(Top-5 vs Bottom-5)
- 换手率(日均换手率，衡量调仓成本)

## 6. 组合管理 (Portfolio)

### 6.1 仓位计算

```
目标仓位 = 择时信号(0/50%/100%) × 等权(1/N)

每日流程:
1. 获取择时信号 → 确定总仓位百分比
2. 获取 StockRank Top-5 → 确定标的
3. 目标持仓 = 总仓位 / 5, 对每只标的
4. 按股价计算可买手数(向下取整到100股)
5. 剩余资金保留为现金
```

### 6.2 调仓规则

- **调仓频率**: 每日收盘后计算信号，次日开盘执行
- **调仓触发**: 择时信号变化 OR StockRank Top-5 名单变化
- **T+1 约束**: 当日买入的股票不能当日卖出
- **涨跌停过滤**: 涨停不追买(无法买入)，跌停不卖出(无法卖出)
- **最小交易单位**: 100 股(一手)
- **价格限制过滤**: 当日开盘价即涨停/跌停的股票，跳过该笔交易

### 6.3 交易成本模型

| 费用项 | 费率 | 说明 |
|--------|------|------|
| 佣金 | 万分之 2.5 (双边) | 单笔最低 5 元 |
| 印花税 | 千分之 0.5 (卖出) | 2023年8月28日后减半 |
| 滑点 | 万分之 5 (双边) | 模拟冲击成本 |

## 7. 回测引擎 (Engine)

### 7.1 回测参数

| 参数 | 值 |
|------|-----|
| 初始资金 | 100,000 元 |
| 回测区间 | 2021-04-09 ~ 2026-04-09 |
| 交易频率 | 日频 |
| 基准 | 创业板指(399006.SZ) |
| 无风险利率 | 2.5% (年化) |

### 7.2 回测流程(逐日)

```
for each trading_day:
    1. 更新行情数据(当日开高低收量)
    2. 检查持仓:涨跌停限制、停牌处理
    3. 计算择时信号(用截止昨日的数据，避免前视偏差)
    4. 计算 StockRank 得分(用截止昨日的数据)
    5. 生成目标持仓
    6. 计算调仓差异(目标 vs 当前)
    7. 执行交易(T+1检查、涨跌停过滤、最小手数)
    8. 计算当日持仓市值
    9. 记录净值、持仓、交易日志
```

### 7.3 数据划分(避免前视偏差)

```
|-------- 训练期 --------|-- 验证期 --|--- 回测期(样本外) ---|
2019-01-01          2020-12-31  2021-06-30           2026-04-09
                                    ↑
                              第一次可交易日

滚动重训: 每 6 个月用所有历史数据重训 LSTM
```

- 需额外拉取 2019-01-01 ~ 2021-04-08 的数据用于初始训练
- 实际回测区间: 2021-04-09 ~ 2026-04-09 (约 5 年)
- LSTM 每 6 个月滚动重训一次，共约 10 次重训

### 7.4 绩效指标

| 指标 | 说明 |
|------|------|
| 年化收益率(CAGR) | 复合年增长率 |
| 夏普比率(Sharpe) | (年化收益 - 无风险) / 年化波动率 |
| 最大回撤(MaxDD) | 最大峰谷跌幅 |
| 卡玛比率(Calmar) | CAGR / MaxDD |
| 胜率(Win Rate) | 盈利交易占比 |
| 盈亏比(Profit Factor) | 总盈利 / 总亏损 |
| 年化换手率 | 衡量交易频率和成本 |
| 超额收益(Alpha) | 相对创业板指的超额 |
| 最长回撤期 | 净值恢复新高的最长时间 |

### 7.5 输出物

- 净值曲线图(策略 vs 创业板指)
- 月度/年度收益热力图
- 回撤曲线图
- 持仓变动日志(CSV)
- 绩效报告(Markdown)
- 每次 LSTM 重训的训练指标

## 10. 风险提示与已知局限

1. **过拟合风险**: LSTM 在小样本(5年日线~1200条)上容易过拟合，滚动重训 + Dropout + 早停是缓解手段
2. **因子衰减**: StockRank 因子权重为静态设定，未做因子有效性检验，后续可加 IC/IR 动态调权
3. **前视偏差**: 财务数据严格按披露日期使用，但 tushare 的 `fina_indicator` 部分字段可能存在回溯修正
4. **流动性约束**: 10万本金的买入对市场无冲击，但创业板部分小盘股流动性差，涨跌停频繁
5. **印花税调整**: 2023-08-28 印花税减半，回测中需分段处理
6. **创业板注册制**: 2020-08-24 后创业板涨跌停从 10% 扩大到 20%，回测中需处理
7. **幸存者偏差**: 使用当时截面的创业板股票池，而非当前截面(需用 `stock_basic` 的 list_date/delist_date 过滤)
